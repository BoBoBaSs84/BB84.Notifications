Remarks

This class maintains a history of values up to a specified size, enabling the ability to move forward and backward through the recorded values. It is useful for scenarios where undo/redo functionality or value tracking is required. When the history is full the behaviour is controlled by the OverflowStrategy supplied at construction time (default: EvictOldest).
