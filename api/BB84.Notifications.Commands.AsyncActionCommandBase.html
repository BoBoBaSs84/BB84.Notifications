Remarks

This class owns the CancellationTokenSource of the running operation, the executing flag that suppresses re-entrant execution, and the cancel command. The cancel command is created once per instance so that subscribers to its CanExecuteChanged event survive, and it is notified whenever the owning command's executability changes.
