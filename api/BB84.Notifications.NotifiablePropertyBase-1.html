Remarks

This class owns the value, the equality comparer used to detect changes, and both notification events. Derived types add their own behaviour by overriding OnValueChanging(T), which runs after the value is known to have changed but before any notification is raised and can veto the assignment entirely.

Remarks

Use this when the derived type is restoring a value it already owns - navigating an existing history, for example - so that the side effects of OnValueChanging(T) are not applied a second time.

Remarks

Derived types override this to attach behaviour to a change, and may return false to abort the assignment so that no notification is raised. The default implementation accepts every change.
